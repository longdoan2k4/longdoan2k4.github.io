## 1. C# là gì?
- C# (C-Sharp) là ngôn ngữ lập trình hướng đối tượng do Microsoft phát triển.
- Được sử dụng rộng rãi trong phát triển phần mềm, ứng dụng desktop, web, game (Unity), IoT...
- C# chạy trên nền tảng .NET.

## 2. Lịch sử phát triển
- Ra mắt năm 2000 cùng với .NET Framework.
- Được cập nhật liên tục với nhiều tính năng hiện đại.

## 3. Ứng dụng thực tế
- Phát triển phần mềm doanh nghiệp (WinForms, WPF, ASP.NET).
- Lập trình game với Unity.
- Ứng dụng di động (Xamarin, MAUI).

## 4. Vì sao nên học C#?
- Cú pháp hiện đại, dễ tiếp cận.
- Được hỗ trợ mạnh mẽ từ Microsoft và cộng đồng.
- Cơ hội việc làm cao.
